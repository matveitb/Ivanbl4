# Как запустить поиск дамоса на своей машине

Шаги для Windows. На Linux и Mac всё то же, только `python3` вместо
`python` и `/` вместо `\`.

## Шаг 1. Поставить Python

Если он уже есть -- пропустите. Проверить: открыть командную строку и
набрать `python --version`. Должно ответить `Python 3.что-то`.

Если нет: https://www.python.org/downloads/ -> большая жёлтая кнопка.
**При установке обязательно поставить галочку «Add python.exe to PATH»**
на самом первом экране. Без неё команда `python` работать не будет.

Ничего дополнительно ставить не нужно -- скрипты написаны на том, что
идёт в комплекте с Python.

## Шаг 2. Скачать этот проект

Один файл, 1-2 МБ:

https://github.com/matveitb/Ivanbl4/archive/refs/heads/claude/kia-spectra-firmware-mapping-uou964.zip

Распаковать куда удобно, например в `D:\spectra`.

## Шаг 3. Открыть командную строку в этой папке

В проводнике зайти в распакованную папку (ту, где лежат `tools`, `docs`,
`firmware`), нажать **Shift + правая кнопка мыши** на пустом месте ->
«Открыть окно PowerShell здесь» или «Открыть окно команд».

Либо: в адресной строке проводника набрать `cmd` и нажать Enter.

## Шаг 4. Запустить

Одна команда. Ссылку на папку взять из адресной строки браузера,
**обязательно в кавычках** -- в ней пробелы и кириллица:

```
python tools\hunt.py "https://cloud.mail.ru/public/RiNt/JAGmbYraM/База прошивок новая/WinOLS/Дамосы 800 гигабайт!"
```

Дальше скрипт всё делает сам и печатает, что происходит:

```
======================================================================
Шаг 1. Читаю список файлов публичной папки
======================================================================
  папок пройдено 1, файлов найдено 240

======================================================================
Шаг 2. Проверяю первый архив: отдаёт ли сервер куски
======================================================================
  base.part1.rar
  размер 1.0 ГБ, Range да

======================================================================
Шаг 3. Читаю оглавления 240 архивов (в 8 потоков)
======================================================================
  [  1/240] base.part1.rar          rar5  записей  3412, подошло 0
  [  2/240] base.part2.rar          rar5  записей  2980, подошло 2
  ...

  скачано всего: 23.4 МБ

======================================================================
Итог
======================================================================

-- точное попадание: 1
   Kia/M7.9.7/1037368793.dam
      из https://cloclo__.datacloudmail.ru/weblink/view/...
```

Всё найденное складывается в `найдено.txt` рядом со скриптом.

## Шаг 5. Достать и проверить кандидата

Скопировать ссылку и имя из отчёта:

```
python tools\remotels.py "ССЫЛКА-ИЗ-ОТЧЁТА" --get "ИМЯ-ИЗ-ОТЧЁТА" --dest firmware\
python tools\damoscore.py firmware\ИМЯ
```

`damoscore` печатает одно число -- сколько цепочек заякорилось.
**Наш нынешний `px5ns03d.dam` даёт 4.** Кандидат стоит внимания, если
даст больше; настоящий M7.9.7 от родственного мотора должен дать
десятки.

`--get` работает для ZIP. Если архив RAR или 7z -- скачайте его целиком
(теперь вы знаете, какой именно из 240, а не все) и распакуйте обычным
архиватором, дальше `damoscore` по файлу.

## Если что-то пошло не так

**`python: command not found` или «не является внутренней командой»** --
не поставлена галочка «Add python.exe to PATH». Переустановите Python с
этой галочкой либо пишите полный путь, например
`C:\Users\Вы\AppData\Local\Programs\Python\Python312\python.exe`.

**`Range НЕТ`** -- сервер не отдаёт куски файла. Тогда весь приём не
работает, и я об этом честно предупреждал. Напишите -- будем думать
дальше.

**Скрипт ругается на папку** -- API mail.ru мог поменяться. Запустите

```
python tools\cloudmail.py "ССЫЛКА" --raw
```

и пришлите, что он напечатает. Починить разбор -- пять минут.

**Уже скачали часть архивов и хотите проверить их** -- ссылка не нужна:

```
python tools\hunt.py --local D:\путь\к\архивам
```

Ищет тем же набором ключей по локальным файлам, через 7-Zip.

## Что именно ищется

| Приоритет | Ключ |
|---|---|
| точное попадание | `1037368793`, `0261208504`, `FBH3ID60`, `391102X3350` |
| Kia/Hyundai на M7.9.7 | kia, hyundai, spectra, shuma, cerato, accent, getz, elantra + M7.9.7 |
| любой M7.9.7 | `M7.9.7`, `10373687xx`, `10373686xx` |
| соседнее семейство | `M7.9`, `ME7.9`, `MSE7.9` |

Плюс в отчёт попадает всё с расширением `.dam`, `.a2l`, `.ols`, `.kp`
даже без совпадения по ключу -- вдруг названо не по номеру.
