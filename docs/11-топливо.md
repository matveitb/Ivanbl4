# Топливо: где оно правится

## Поправка к первой редакции

Первая редакция этого документа содержала две ошибки, и обе разобраны ниже,
потому что причина у них общая.

**Было сказано:** шаг кривой 0.195 % на единицу, авторы обедняют смесь на 2-5 %.
**На самом деле:** шаг 0.78 % на единицу, авторы **обогащают** на 8-13 %.

Причина. Масштаб был подобран под фразу «csok v2 отличается от csok топливом
примерно на 0.3 %»: из двух подходящих пересчётов DAMOS был выбран тот, что
давал 0.39 %, а не 1.56 %. Это подгонка под пересказанную цифру вместо поиска
независимого доказательства. Выбрав неверный масштаб, я вдобавок заявил
направление («обедняют»), не установив смысла самой величины.

**Как установлено правильно.** Управляемый эксперимент на паре нивовских
прошивок `B103eq09` / `B103eq09_1.5`: в ChipTuningPRO выставлена `alpha = 1.5`
по всей карте. В образе изменились ровно 192 байта, со **128 на 192**.

```
128 -> alpha 1.000
192 -> alpha 1.500
```

Отсюда однозначно **alpha = сырое / 128**, шаг 0.78 %. И это коэффициент
избытка воздуха, то есть **меньше 1.000 = богаче**, больше = беднее.

## Карта «Альфа» = KFLF

Тот же эксперимент опознал карту. Правка alpha затронула карту 16x12 из одних
128 по адресу `0x1919E` в нивовской прошивке. В FBH3ID60 единственная такая же
карта — **`KFLF` по `0x190EC`**, которую DAMOS называет «lambda characteristic
map at part load». Это и есть «Альфа» в терминах ChipTuningPRO.

**Во всех одиннадцати прошивках Kia она равна 128, то есть alpha 1.000.**
Её не трогает никто.

## Чем на самом деле правят топливо

| Что | Адрес | Меняли |
|---|---|---|
| Кривые обогащения по температуре | `0x1955B`, `0x19568` | **все без исключения** |
| `KFLBTS` — лямбда защиты компонентов | `0x19636` | 6 вариантов из 11 |
| `KFLF` («Альфа») | `0x190EC` | никто |
| `KRKTE` — константа форсунки | `0x19485` | никто |
| `TEMIN` / `TEMINVA` | `0x15E44` / `0x15E46` | никто |

### Кривые обогащения

Две кривые по шесть точек с общей осью, `alpha = сырое / 128`.

```
0x1955B: счётчик 6, ось 0x1955C, данные 0x19562
0x19568: счётчик 6, ось 0x19569, данные 0x1956F
```

Ось `37 62 87 112 137 162` при шкале x0.75-48 это температура
**-20.2 … +73.5 °C**.

| Прошивка | Кривая (-20 … +73 °C) | Обогащение |
|---|---|---|
| сток, `Spectra ori_e3` | 1.000 везде | 0 % |
| `csok` | 0.906 … 0.859 | **+11.6 %** |
| `csok v2` | 0.891 … 0.844 | **+13.2 %** — богаче `csok` |
| `MPower` | 1.023 равномерно | **-2.3 %** — единственный обедняет |
| `Spectra mod` | 1.000 → 0.852 | +8.1 % |
| `Xstart` / `Xoptim` | 0.805…0.883 / 0.883…0.867 | +13.3 % / +12.6 % |
| `startpower`, `NI_startpower` | как `csok` | +11.6 % |
| `FBH3ID60_L` | 0.906 … 0.805 | +12.5 % |

Почти все обогащают на 8-13 %, и сильнее на прогретом двигателе.

### KFLBTS

Тот же знак: меньше = богаче.

| Прошивка | Минимум | Среднее |
|---|---|---|
| сток, `Spectra ori/mod` | 0.766 | 0.9450 |
| `csok`, `csok v2`, `startpower` | 0.844 | 0.9402 |
| `FBH3ID60_L` | **0.727** | 0.8967 |
| `MPower`, `Xstart`, `Xoptim` | **1.000** | **1.0000** |

## Итог по MPower

`MPower` обедняет дважды: `-2.3 %` по кривым и `KFLBTS` ровно 1.000, то есть
обогащение защиты компонентов снято полностью. Все остальные наоборот
обогащают. `csok` с его `+11.6 %` и `KFLBTS` 0.844 заметно богаче `MPower` —
это подтверждается и цифрами, и словами калибровщика.

## Чего установить не удалось

Заводского имени кривых `0x1955B` / `0x19568`. Оси `37 62 87 112 137 162` нет
в нивовской прошивке, в DAMOS эта область расходится между M7.9 и M7.9.7,
ссылок из кода нет (читающая процедура, судя по всему, в сегменте 0, которого
в дампе нет). Адрес, структура, ось, масштаб и знак — установлены и проверены.

## Где всё-таки «топливная карта»

Вопрос возвращается, поэтому коротко и по адресам. Таблицы наполнения или
миллисекунд в M7.9.7 нет вообще. Цепочка такая:

```
rl (наполнение из ДМРВ)
   / lambda_зад             <- это и задают «топливные» карты
   = rk, относительная масса топлива, %
   * KRKTE                  <- постоянная форсунки, мс на %
   = te, эффективное время впрыска
   + TVUB                   <- добавка на напряжение (время открытия форсунки)
   = ti, что уходит на форсунку
```

### Что задаёт цель по смеси

| адрес | имя | размер | сток |
|---|---|---|---|
| 0x190EC | `KFLF` | 12 строк нагрузки x 16 столбцов оборотов, raw/128 | **1.000 во всех 192 ячейках** |
| 0x19636 | `KFLBTS` | 12 x 16, x0.0078125 | обогащение на полной нагрузке |

`KFLF` -- это и есть «Альфа» из ChipTuningPRO, ближайшее к тому, что
обычно называют топливной картой. В стоке она ровно единица везде, и так
во всех восьми прошивках: на частичных нагрузках блок держит стехиометрию
по датчику кислорода, и карта тут ни при чём.

`KFLBTS` -- единственная топливная карта, которую тюнеры реально правили.

### Что задаёт количество

| адрес | имя | сток | что |
|---|---|---|---|
| 0x19485 | `KRKTE` | 0.1637 мс на % | постоянная форсунки |
| 0x190CD | `FRKAP` | 1.000 | глобальный множитель массы топлива, шаг 1/128 = 0.78 % |
| 0x15E44 | `TEMIN` | 0.219 мс | минимальное время впрыска |

`KRKTE` сходится с физикой. Полный цилиндр 1.6/4 при нормальных условиях --
517 мг воздуха, то есть 35.2 мг бензина при стехиометрии. При rk = 100 %
получается te = 16.37 мс, отсюда расход форсунки 129 г/мин, около
172 см3/мин -- обычный размер для 1.6. Прямой ссылки кода на этот адрес
`calref` не нашёл, поэтому уверенность «вероятная», а не «подтверждена».
Это единственное место, где учитывается размер форсунок: ставите другие --
правите здесь.

`FRKAP` подтверждён ссылкой кода 0x517DA. Это буквально ручка «добавить
топлива везде»: 1.000 во всех восьми прошивках, шаг 0.78 % на единицу.

Итого: `KFLF`, `KRKTE` и `FRKAP` не тронул никто. Всё обогащение во всех
имеющихся прошивках сделано одной картой -- `KFLBTS`.
