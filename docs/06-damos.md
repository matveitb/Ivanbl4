# DAMOS: имена, описания и масштабы

## Что дал ваш файл

`firmware/px5ns03d.dam` — заводское описание калибровок (формат ASAP2DAM 6.28)
для прошивки **px5ns03d** блока **Bosch M7.9**. Это не та же прошивка, что
FBH3ID60 (M7.9.7), но родственная: тот же порядок калибровочных структур,
те же имена переменных, те же пересчёты.

Из него получено:

- **2447 переменных** с именами и текстовыми описаниями;
- **333 формулы пересчёта** в физические единицы;
- **карта памяти**, подтверждающая то, что было выведено из таблицы сумм.

Плюс к DAMOS приложены `px5ns03d.BIN` (полный образ адресного пространства
0x000000–0x87FFFF) и `px5ns03d.hex` (Intel HEX). Проверено: HEX и BIN
побайтово совпадают на участке флеша.

## Карта памяти из DAMOS

```
/SND, CODE1 $800000 $80FFFF     -> файл 0x00000..0x0FFFF
/SND, CODE2 $820000 $87FFFF     -> файл 0x20000..0x7FFFF
/SND, DATA1 $810000 $81FFFF     -> файл 0x10000..0x1FFFF   <- калибровки
```

`DATA1` в точности совпадает с областью, которую независимо дал анализ
энтропии и в которой нашлись все карты FBH3ID60. База флеша `0x800000`
подтверждена.

Отдельно объясняется пропуск в таблице контрольных сумм
(`0x817E68`–`0x81818F`): DAMOS показывает, что там лежат `DISTAB_A/B/C` —
таблицы каналов телеметрии ETK, которые из подсчёта сумм исключены.

## Грамматика записи

```
<idx>, /SPZ, <ИМЯ>, {<описание>}, <тип>, <адрес>, <адрес2>
/SPW, <id_пересчёта>, <знаков>, <физ_мин>, <физ_макс>      -- значения
/SPX, <id_пересчёта>, <знаков>, <мин>, <макс>, <ссылка>    -- ось X (строки)
/SPY, <id_пересчёта>, <знаков>, <мин>, <макс>, <ссылка>    -- ось Y (столбцы)
/FKX, <точек_X>, 0, 0
/FKY, <точек_Y>, 0, 0
/ABL, <n>;
```

Пересчёт задаётся парой:

```
<idx>, /REG, <имя>, {}, <тип>, <?>, {<единица>}, <знаков>, <?>, <мин>, <макс>
/REP, <raw_max>, <смещение>, <?>, <размах>, 0, 0;
```

и вычисляется как

```
физ = сырое * размах / raw_max - смещение / raw_max
```

Имя пересчёта кодирует масштаб: `q0p75` = квант 0.75, `o6p25` = смещение 6.25,
`ub`/`sb` = беззнаковый/знаковый байт, `uw`/`sw` = слово.

## Типы записей

| Тип | Смысл | Раскладка в образе |
|---|---|---|
| 1 | скаляр | одно значение |
| 2 | кривая с внешней осью | байт длины, затем данные |
| 3 | карта с заголовком | `nx`(строки), `ny`(столбцы), ось X, ось Y, данные |
| 4 | большой массив | голые данные, длина из DAMOS |
| 5, 8 | карта с общими осями | голая сетка, оси хранятся отдельно |
| 6 | ось | байт длины, затем точки |
| 7, 13 | массив/кодовое слово | голые данные |

Тип 3 против типов 5/8 — это ровно те два формата, которые до появления
DAMOS были найдены вручную и потребовали двух разных сканеров
(`mapscan.py` и `gridscan.py`).

## Порядок осей

Важная тонкость: **ось Y меняется быстрее**, то есть Y — это столбцы,
X — строки. Установлено по `KFZWOP`: ось X = `SNM16OPUB` (обороты, 16 точек),
ось Y = `SRL11OPUW` (нагрузка, 11 точек), а карта в образе лежит как
11 в ширину и 16 в высоту.

Ещё тонкость: адрес в DAMOS указывает на **байт длины**, а не на первую
точку. Поэтому ось `SNM16ZUUB` с адресом `$810102` в образе читается как
`n=16` по `0x10102` и значения с `0x10103`.

## Перенос на FBH3ID60

Прошивки родственные, но не идентичные: размеры части таблиц отличаются,
поэтому адреса плывут. `tools/xfer.py` работает в два шага.

**Якоря.** Для записей с проверяемой структурной подписью (типы 3, 6, 2)
ищется точное совпадение в целевой прошивке в окне ±512 байт. Совпадение
принимается только если оно единственное.

Результат: из 342 записей с проверяемой подписью **283 подтвердились в
самом px5ns03d** (это проверка правильности разбора DAMOS), и **159 нашлись
в FBH3ID60**. Преобладающий сдвиг +1 байт, но встречаются +7, +62, +206 —
выравнивание действительно кусочное.

**Выравнивание.** Якоря задают кусочную функцию сдвига, через неё
переносятся остальные записи — уже без гарантии.

**Независимая проверка.** Для каждой перенесённой карты детектор ширины из
`gridscan.py` проверяет, что тело действительно имеет обещанную ширину.
Из 158 многомерных карт: **58 подтверждены**, 61 не сошлась, 39 проверить
нечем (константные или слишком мелкие).

Отсюда градация достоверности в итоговой разметке:

| Достоверность | Что значит |
|---|---|
| подтверждена | найдено структурно либо тело подтверждено детектором ширины |
| вероятная | перенесено выравниванием, противоречий не найдено |
| сомнительная | перенесено выравниванием, тело не сходится с ожидаемой шириной |

Сомнительные строки в WinOLS надо проверять глазами, а лучше не трогать.

## Ограничение

DAMOS относится к **другой прошивке**. Имена, описания и масштабы переносятся
надёжно — они общие для семейства M7. Адреса переносятся лишь настолько,
насколько совпадает раскладка, и именно поэтому каждая перенесённая карта
несёт отметку достоверности. Там, где прошивки расходятся (например, район
`0x19562`), перенос не даёт ничего, и такие области остаются безымянными.
