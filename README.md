# Разметка прошивки Kia Spectra 1.6 — Bosch M7.9.7 (Infineon C167)

Разметка калибровочных карт прошивки **FBH3ID60** (блок Bosch `0261208504`,
ПО `1037368793`, OEM `391102X3350`) и инструменты для работы с ней.

## Что уже установлено

- **Контрольные суммы решены полностью.** Таблица `0x1FC00`, сумма 16-битных
  слов; 32 записи из 34 сходятся точно на всех трёх прошивках. Правленый файл
  можно готовить к заливке одной командой.
- **Найдены все три карты зажигания** — `0x10529` (11x16), `0x10A01` (12x15),
  `0x10AB5` (12x16). Масштаб `0.75 °/ед.` практически подтверждён: сток даёт
  24° на холостом ходу и до 45° на высоких оборотах при малой нагрузке.
- **Разобрано, что сделал калибровщик**: до +6.75° к зажиганию в области
  средних и высоких нагрузок, отключена часть флагов диагностики
  (`0x10009`–`0x10027`), правки ещё в нескольких таблицах.
- **Разница между двумя csok** — ровно +0.75° в блоке средних оборотов.
- **193 карты** в итоговой разметке, из них 7 проверены вручную.

Подробности: [docs/05-находки.md](docs/05-находки.md).

## Быстрый старт

```bash
./analyze.sh
```

Прогоняет весь конвейер на файлах из `firmware/`. Результаты в `out/`:

| Файл | Что это |
|---|---|
| `out/РАЗМЕТКА.md` | Отчёт по всем найденным картам |
| `out/FBH3ID60.a2l` | Импортировать в WinOLS |
| `out/FBH3ID60.csv` | Та же таблица для Excel |
| `out/IGN_*.txt` | Карты зажигания: сток против обеих csok |
| `out/diff_stock_csok1.txt` | Всё, что калибровщик менял относительно стока |

Посмотреть карту зажигания в градусах:

```bash
python3 tools/showmap.py --profile profiles/FBH3ID60.json \
    --name IGN_MAIN_11x16 --scale 0.75 --unit град \
    firmware/FBH3ID60_stok.bin "firmware/FBH3ID60 e2 tun csok.bin"
```

Пересчитать суммы после правки:

```bash
python3 tools/bosch_csum.py fix правленая.bin -o готовая.bin
```

## Инструменты

| Файл | Назначение |
|---|---|
| `tools/fwinfo.py` | Обзор образа: энтропия, границы код/калибровки, строки, ID блока |
| `tools/fwdiff.py` | Дифф двух прошивок с группировкой правок и распознаванием карт |
| `tools/mapscan.py` | Карты классического формата Bosch (`nx, ny, X, Y, D`) |
| `tools/gridscan.py` | Голые таблицы без заголовка — ими лежат карты зажигания |
| `tools/axisscan.py` | Оси, в том числе цепочечным разбором |
| `tools/bosch_csum.py` | Проверка и пересчёт контрольных сумм |
| `tools/showmap.py` | Печать карты из нескольких прошивок с матрицей разностей |
| `tools/hexdump.py` | Дамп участка с подсветкой отличий |
| `tools/report.py` | Сборка итоговой разметки: A2L, CSV, отчёт |
| `tools/a2lgen.py` | Экспорт только из `mapscan` (частный случай `report.py`) |
| `tools/ghidra/ImportMaps.py` | Импорт разметки в Ghidra |
| `analyze.sh` | Весь конвейер одной командой |

Зависимостей нет, только Python 3.8+. Полный прогон — несколько секунд.

## Проверки

```bash
python3 tests/test_fbh3id60.py   # на реальных прошивках: суммы, карты, оси
python3 tests/test_mapscan.py    # на синтетическом образе с известным ответом
```

Первый фиксирует установленные факты, второй проверяет сканер там, где
правильный ответ известен заранее (10 из 10 карт, 0 ложных).

## Что осталось открытым

**Оси карт зажигания.** Карты `0x10529`, `0x10A01`, `0x10AB5` лежат голыми
сетками, их оси общие и хранятся отдельно. Ни одна из 45 найденных осей не
имеет 11 точек, поэтому ось нагрузки для главной карты не привязана.
Решается чтением кода — ссылки на карты уже найдены, см.
[docs/04-ghidra.md](docs/04-ghidra.md).

**Масштабы остальных карт.** A2L выгружается с сырыми значениями намеренно:
угаданный множитель даёт правдоподобную, но неверную картинку. Для зажигания
множитель 0.75 подтверждён практикой, для прочих карт подбирается в WinOLS.

## Предупреждение

Изменённая прошивка не заведётся без пересчёта контрольных сумм. Всегда
сохраняйте исходный дамп. Ваши две csok — рабочий эталон: сверяйтесь с ними
через `tools/fwdiff.py`, чтобы не задеть лишнего.
