# Разметка прошивки Kia Spectra 1.6 — Bosch M7.9.7 (Infineon C167)

Набор инструментов для поиска и разметки калибровочных карт в прошивках
Bosch M7.9.7 с последующим импортом в WinOLS.

> **Статус: прошивки в репозиторий не попали.** Файлы (две `csok` и сток)
> не дошли до рабочей среды — каталог `firmware/` пуст. Инструменты написаны
> и проверены на синтетическом образе; как только вы положите файлы в
> `firmware/`, весь анализ запускается одной командой.

## Быстрый старт

```bash
# 1. Положите прошивки
cp /путь/stock.bin  firmware/stock.bin
cp /путь/csok1.bin  firmware/csok1.bin
cp /путь/csok2.bin  firmware/csok2.bin

# 2. Полный прогон
./analyze.sh firmware/stock.bin firmware/csok1.bin firmware/csok2.bin

# 3. Результаты — в out/
#    out/stock.a2l   <- импортировать в WinOLS
#    out/stock.csv   <- список карт таблицей
#    out/diff_csok1_csok2.txt <- КАРТЫ ЗАЖИГАНИЯ, найденные по диффу
```

## Главная идея

Две ваши прошивки `csok` отличаются **только углами зажигания**. Это самый
ценный факт во всей задаче: побайтовый дифф двух файлов даёт **точные адреса
и размеры тел карт зажигания** — без реверса, без дизассемблера, без догадок.

Дальше `fwdiff --identify` сканирует назад от начала каждой изменённой
области, находит заголовок карты (`nx`, `ny`) и оси — и выдаёт полностью
готовое описание карты.

Проверено на синтетическом образе: 3 заложенные карты зажигания найдены все,
с точными адресами заголовков, размерностями и разрядностями.

## Инструменты

| Файл | Назначение |
|---|---|
| `tools/fwinfo.py` | Обзор образа: энтропия по блокам, границы код/калибровки, строки, ID блока |
| `tools/fwdiff.py` | Дифф двух прошивок, группировка правок, достраивание структуры карты |
| `tools/mapscan.py` | Сканер карт по всему образу (формат Bosch `nx,ny,X,Y,D`) |
| `tools/a2lgen.py` | Экспорт в A2L (ASAP2) и CSV для WinOLS |
| `tools/checksum.py` | Поиск ячеек контрольных сумм |
| `tools/ghidra/ImportMaps.py` | Импорт найденных карт в Ghidra как метки и данные |
| `analyze.sh` | Прогон всего конвейера |

Зависимостей нет — только Python 3.8+. Полное сканирование 512 КБ ≈ 1 секунда.

## Проверка инструментов

```bash
python3 tests/make_synthetic.py out/synth   # сгенерировать тестовый образ
python3 tests/test_mapscan.py               # прогнать проверки
```

Ожидаемый результат: `Заложено карт: 10 / Найдено: 10 / Ложных: 0`,
все карты зажигания покрыты диффом, `ВСЕ ПРОВЕРКИ ПРОЙДЕНЫ`.

## Важное предупреждение

Изменённая прошивка не заведётся, пока не пересчитаны контрольные суммы.
См. `docs/02-методика.md`, раздел «Контрольные суммы». Всегда сохраняйте
исходный дамп до правок.
