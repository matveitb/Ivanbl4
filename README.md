# Разметка прошивки Kia Spectra 1.6 — Bosch M7.9.7 (Infineon C167)

Разметка калибровок прошивки **FBH3ID60** (блок Bosch `0261208504`,
ПО `1037368793`, OEM `391102X3350`) с именами, описаниями и масштабами
из заводского DAMOS.

## Главное

- **650 карт и кривых** в итоговой разметке — с именами Bosch, описаниями
  и реальными масштабами пересчёта в физические единицы.
- **Карты зажигания найдены и названы**: `KFZWOP` (`0x10529`, 11x16),
  `KFZW` (`0x109F5`, 12x16), `KFZW2` (`0x10AB5`, 12x16),
  `KFZWMS` (`0x10935`), `KFZWMN` (`0x14DA4`). Масштаб **0.75 град KW/ед.**
  подтверждён DAMOS (`zw_sb_q0p75`), обороты — **x40 об/мин** (`nmot_ub_q40`).
- **Контрольные суммы решены полностью** — правленый файл готовится к
  заливке одной командой.
- **Разобрано, что сделал калибровщик** — с именами карт и в градусах.

Подробности: [docs/05-находки.md](docs/05-находки.md).

## Что сделал калибровщик

| Карта | Изменение | Смысл |
|---|---|---|
| `KFZW` | +2.25..+11.25 град | основная карта зажигания раньше |
| `KFZWOP` | +0.75..+6.75 град | оптимальный угол раньше |
| `KFZW2` | +0.75..+5.25 град | вариант 2 раньше |
| `KFZWMS` | было -24.75 везде, стало до +11.25 | поднят предел позднего угла |
| `KFZWMN` | +14.25..+28.5 град | поднят минимальный угол |
| `KFLBTS` | 0.766..1 -> 0.844..1 | лямбда защиты компонентов беднее |
| `KFDZWKG` | +0.75..+3 град | коррекция по границе детонации |

Плюс обнулена часть флагов диагностики (`0x10009`–`0x10027`).
Две ваши csok отличаются ровно на **+0.75 град** в трёх картах зажигания.

Полностью: [results/ЧТО_ИЗМЕНЕНО.md](results/ЧТО_ИЗМЕНЕНО.md).

## Быстрый старт

```bash
./analyze.sh
```

Результаты в `out/` (готовая копия — в `results/`):

| Файл | Что это |
|---|---|
| `ЧТО_ИЗМЕНЕНО.md` | Что калибровщик менял относительно стока, с именами и в градусах |
| `ЧТО_ИЗМЕНЕНО_csok1_csok2.md` | Разница между двумя csok |
| `РАЗМЕТКА.md` | Все 650 карт с масштабами и достоверностью |
| `FBH3ID60.a2l` | Импортировать в WinOLS — с масштабами и знаковостью |
| `FBH3ID60.csv` | Та же таблица для Excel |
| `KFZW*.txt` | Карты зажигания: сток против обеих csok |

Посмотреть карту в градусах:

```bash
python3 tools/showmap.py --profile profiles/FBH3ID60.json --name KFZWOP \
    --scale 0.75 --unit град firmware/FBH3ID60_stok.bin \
    "firmware/FBH3ID60 e2 tun csok.bin"
```

Пересчитать суммы после правки:

```bash
python3 tools/bosch_csum.py fix правленая.bin -o готовая.bin
```

## Инструменты

| Файл | Назначение |
|---|---|
| `tools/damos.py` | Разбор DAMOS: имена, описания, формулы пересчёта |

| `tools/mapscan.py` | Карты классического формата Bosch |
| `tools/axisscan.py` | Оси, в том числе цепочечным разбором |
| `tools/fwdiff.py` | Дифф двух прошивок с группировкой правок |
| `tools/fwinfo.py` | Обзор образа: энтропия, границы, строки, ID блока |
| `tools/showmap.py` | Печать карты из нескольких прошивок с разностями |

Зависимостей нет, только Python 3.8+. Полный прогон — несколько секунд.

## Достоверность

Разметка размечена по уровням, и это важно:

| Уровень | Что значит |
|---|---|
| подтверждена | найдено структурно либо тело подтверждено независимой проверкой |
| вероятная | перенесено выравниванием из DAMOS, противоречий нет |
| сомнительная | тело не сходится с ожидаемой шириной — проверять глазами |

DAMOS относится к родственной прошивке (M7.9 `px5ns03d`), а не к вашей.
Имена, описания и масштабы переносятся надёжно — они общие для семейства M7.
Адреса переносятся лишь настолько, насколько совпадает раскладка.

## Предупреждение

Изменённая прошивка не заведётся без пересчёта контрольных сумм. Всегда
сохраняйте исходный дамп.
