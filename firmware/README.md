# Сюда кладутся прошивки

Ожидаемые файлы:

- `stock.bin`  — стоковая прошивка
- `csok1.bin`  — первая прошивка csok
- `csok2.bin`  — вторая прошивка csok (отличается углами зажигания)

Имена могут быть любыми — они передаются в `analyze.sh` аргументами:

```bash
./analyze.sh firmware/stock.bin firmware/csok1.bin firmware/csok2.bin
```

Двоичные файлы прошивок по умолчанию не коммитятся (см. `.gitignore`).
Если хотите хранить их в репозитории, уберите соответствующие строки
из `.gitignore`.

## ctp7/

Сверка с ChipTuningPRO 7 (docs/35): экспорт калибровок MPower из CTP7
(`.cte`), прошивка после правок владельца в CTP7 (`_test.bin`), список этих
правок (`v1.txt`) и итог `tools/ctematch.py` (`ctematch.json`). Второй раунд
-- `_test2.bin` и `_test2.cte`, правки всего, что по значению не различалось,
итог в `ctematch2.json`.

**`_test2.bin` в машину не шить**: там нарочно выставлены значения для
опознания (состав смеси на частичных 0.52, минимальный УОЗ -1.5, режим 3
вентилятора 143 °C и т. п.), ездить на этом нельзя.

## FBH3ID60_v2M_zw-2.bin

Тест гипотезы «провал на 100 % педали -- откат по детонации» (docs/39). Это
v2M, у которой в `KFZW` и `KFZW2` угол убавлен на 2.25 град в зоне 1520..3520
об/мин при нагрузке от 50 %. Больше ничего не менялось. Контрольные суммы
пересчитаны редактором, проверка `tools/bosch_csum.py check`: 32 из 32.

## FBH3ID60_v2M_rich.bin

Второй тест причины провала (docs/39): v2M с обогащением на полной нагрузке.
KLLAMFA_0 и KLLAMFA_1 выставлены на лямбда 0.89 (было 1.023, без обогащения),
угол НЕ тронут. Пара к v2M_zw-2 (угол) разводит две причины: детонация
против бедной смеси. Суммы пересчитаны, bosch_csum check: 32 из 32.

## FBH3ID60_v2M_lc.bin

v2M с лаунч-контролем (docs/40): `tools/launch.py apply` с параметрами по
умолчанию -- стоя (скорость до 2.5 км/ч), газ от 70 %, ОЖ от 60 °C подача
отключается выше 4200 об/мин и возвращается ниже 4000. Калибровки v2M не
тронуты. Это **первая правка кода** в проекте: врезка 0x3C116 (6 байт),
подпрограмма 0x6FC00 (78 байт), параметры 0x17000 (7 байт). Суммы
пересчитаны, bosch_csum check: 32 из 32. Оригинал v2M держать под рукой;
`tools/launch.py remove` возвращает его байт в байт.
