# Редактор калибровок

Бесплатная замена WinOLS и ChipTuningPRO для того, что нам от них нужно:
открыть прошивку с описанием A2L, увидеть карты деревом, поправить
таблицу, сравнить с другой прошивкой, сохранить с верными контрольными
суммами.

## Запуск

### Готовый .exe для Windows

Собирается автоматически на сборочной машине Windows: вкладка **Actions**
в репозитории → последний зелёный запуск → раздел **Artifacts** →
`CalibrationEditor-windows`. Внутри один файл, ничего ставить не надо —
ни Python, ни Qt. Описание Spectra вложено внутрь, так что после запуска
остаётся выбрать только прошивку.

Почему не лежит готовым в репозитории: PyInstaller не умеет кросс-сборку,
Windows-файл собирается только на Windows. Отсюда и CI.

### Из исходников (любая система)

```
pip install -r ../requirements-editor.txt
python3 -m editor прошивка.bin описание.a2l
```

На чистом Linux одного `pip install` мало — PySide6 тянет системные
библиотеки Qt:

```
sudo apt-get install -y libegl1 libgl1 libxkbcommon0 libxkbcommon-x11-0 \
  libdbus-1-3 libfontconfig1 libxcb-cursor0 libxcb-xinerama0 \
  libxcb-icccm4 libxcb-keysyms1 libxcb-shape0 libxcb-randr0 \
  libxcb-render-util0
```

На Windows этого не нужно: там колёса PySide6 несут всё своё.

### Собрать .exe самому

```
pip install pyinstaller
pyinstaller editor.spec
dist\selftest.exe --selftest firmware\FBH3ID60_stok.bin
```

Вторая команда обязательна. «Собралось» не значит «работает»: половина
импортов в проекте ленивая, и собранный файл спокойно откроется, а упадёт
при нажатии «протянуть». Самопроверка живёт внутри сборки и прогоняет то
же, что делается руками.

Без Qt, из командной строки — то же ядро:

```
python3 -m editor.cli list --a2l results/FBH3ID60_legacy.a2l --bin firmware/FBH3ID60_stok.bin
python3 -m editor.cli show --a2l ... --bin ... --map KFZWOP
python3 -m editor.cli diff --a2l ... --bin сток.bin --other правленая.bin
```

## Раскладка

| что | где |
|---|---|
| `a2l/lexer.py` | токенизатор ASAP2 |
| `a2l/parser.py` | разбор блоков в дерево, ничего не знает про смысл |
| `a2l/model.py` | типизированная модель: CHARACTERISTIC, RECORD_LAYOUT, COMPU_METHOD, AXIS_PTS, GROUP |
| `a2l/geometry.py` | где в файле лежат данные и оси конкретной карты |
| `core/mapaccess.py` | чтение и запись значений |
| `core/edits.py` | операции над выделением, отмена и повтор |
| `core/saving.py` | сохранение с пересчётом сумм, поиск таблицы сумм |
| `core/compare.py` | сравнение двух прошивок в терминах карт |
| `core/project.py` | образ, описание, история и группировка в одном месте |
| `ui/` | окно: дерево, таблица, кривая, поверхность, сравнение, палитра |

Разбор ASAP2 — полноценный, а не регулярка под наш файл: редактор должен
открывать чужие A2L, когда дойдём до других машин.

## Что редактор делает сам

* **Определяет адресацию.** Адреса в A2L бывают абсолютные (`0x810529`) и
  файловые (`0x10529`). База подбирается подсчётом: какой вариант
  укладывает больше карт внутрь образа.
* **Находит таблицу контрольных сумм** по форме записи, а не по
  зашитому адресу — значит откроется и чужая прошивка Bosch.
* **Читает настоящее число точек оси из файла.** В A2L записан
  максимум (`MaxAxisPoints`), а не факт.
* **Разбирает блок по номерам позиций в раскладке,** а не по тому, что X
  принято писать раньше Y. У карт Bosch первой в блоке лежит ось строк;
  прочитав X первым только потому, что он называется X, редактор показал
  бы карту транспонированной — на квадратной незаметно, на 16 на 12
  губительно.
* **Запрещает правку там, где не может её честно выполнить** —
  нелинейный пересчёт (`TAB_INTP`, `FORM`) показывается, но не правится.
* **Предупреждает, когда карты делят байты.** Описание не обязано быть
  непротиворечивым: адреса приходят из разных источников, и две карты
  вполне могут претендовать на одни байты. Правку не запрещаем, но под
  таблицей красным сказано, кого ещё она заденет.
