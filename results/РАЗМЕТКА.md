## Контрольные суммы

- Таблица: **0x1FC00**, записи по 16 байт
- Формат записи: `start:u32, end:u32, sum:u32, ~sum:u32`
- Алгоритм: сумма 16-битных LE слов по региону [start..end] включительно, 32-битный аккумулятор
- Проверка: 32 из 34 записей сходятся точно на всех трёх прошивках

Пересчёт: `python3 tools/bosch_csum.py fix вход.bin -o выход.bin`
